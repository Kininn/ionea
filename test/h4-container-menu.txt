# Hold A / Enter or right-click on a container: its quick menu (Open, Rename, Remove container).
# Rename refuses another container's name, Remove asks first (Cancel focused) and its games go back
# to the home row. A short press still opens the container. 12 dummies: 3 in Box, 2 in Shelf.
# Run: --data <tmp> --no-import --dummies 12 --windowed --mute --script test\h4-container-menu.txt
wait 900
type Living Room
key accept
wait 900
key accept
wait 1100
folderfill Box|3
folderfill Shelf|2
expect count 10
# right-click on the Box tile
mousetile right 0
wait 300
expect name folder:Box
expect screen HoldMenu
expect holdrows open,rename,remove
expect holdfocus open
shot launcher-h4-container-menu
key down 5
expect holdfocus remove
key back
wait 400
expect screen HomeScreen
# held down: the same menu, Open opens it
hold 750
expect screen HoldMenu
key accept
wait 800
expect view folder:Box
key back
wait 700
expect view home
# a short press still opens it
expect name folder:Box
hold 150
wait 800
expect view folder:Box
key back
wait 700
# Rename: a name another container has is refused, a new one renames it
