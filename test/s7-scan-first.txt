# The first start on a PC with no emulators (--scan-home <T>\empty --scan-prompt): the scan's screen
# comes by itself and offers Download an emulator, and melonDS's official release (the test server's) installs.
wait 900
type Tester
key accept
wait 900
key accept
wait 1500
waitscan 20
expect screen ScanCard
expect cardrows Download an emulator | Look harder | Done
shot s7-first-none
offline off
online emulators on
cardrow Download an emulator
key accept
wait 500
expect screen EmuInstallCard
shot s7-download-list
cardrow melonDS
key accept
wait 1500
expect screen DownloadCard
expect downloadaddress http://localhost:47812/dl/melonDS-1.1-windows-x86_64.zip
key down
expect cardfocus Download
key accept
waitemuinstall 20
expect emuinstall installed melonDS
expect emus 1
wait 800
shot s7-first-after
quit
