# Menu cleanup: settings sort into the same boxes for any emulator, including
# settings no definition names, and the Settings pages show their rows in boxes.
# Setup: test\w6-menu-cleanup.ps1 (12 dummies, --windowed --mute, off screen). No semicolons in comments.
wait 900
type Tester
key accept
wait 900
key accept
wait 2200
# 1. Any emulator's setting finds a box by its key and name (unknown ones go to Advanced)
expect settinggroup melonds_render_mode|Renderer|Performance
expect settinggroup [Renderer]resolution_setup|Internal resolution|Display
expect settinggroup GPU.fsr_enabled|AMD FSR|Image quality
expect settinggroup mgba_audio_low_pass_filter|Audio low-pass filter|Audio
expect settinggroup mgba_rumble|Rumble|Controls
expect settinggroup [Video]frame_skip|Frame skip|Performance
expect settinggroup snes9x_audio_latency|Audio latency|Audio
expect settinggroup [Core]Sync|Sync to audio|Performance
expect settinggroup some_core_region|Console region|Advanced
expect settinggroup effect_bloom|Bloom|Image quality
# 2. Settings pages in boxes
settings look and layout
expect cardboxes Appearance,Home screen,Window,In games,Intro and outro
expect cardrows Theme | Colours | Icon shape | Reduce effects | Layout | Sort | Screen mode | Game display | Performance overlay | Intro at start | Outro when closing | Watch the intro
shot w6-look
key back
wait 500
settings sound
expect cardboxes Sound,Levels
shot w6-sound
key back
wait 500
settings controls
expect cardboxes Devices,Keys and buttons
key back
wait 500
settings library
expect cardboxes Library,Add,Advanced
key back
wait 500
settings network
expect cardboxes Connection,Sources,Services
shot w6-network
key back
wait 500
settings about and updates
expect cardboxes Ionea,Updates,Previous version
key back
wait 500
