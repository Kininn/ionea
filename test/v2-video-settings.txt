# Shared video settings. Run by v2-video-settings.ps1, which makes the
# test folder T: fake Eden, Lichii, Azahar, Dolphin, melonDS, mGBA and a melonDS DS core that lists nothing.
#  - Every emulator: the shared rows by the same names in the same boxes (no More page, the rest in
#    a box found from their key and name, or the boxes their definition names).
#  - Every game: the emulator's own file (Eden / Azahar with key\default, Dolphin's renderer in Dolphin.ini).
#  - One game: Eden / Lichii / Azahar custom\<id>.ini with use_global, Dolphin GameSettings\<id>.ini in its
#    Video_ sections (an .iso and an .rvz), melonDS and mGBA in Ionea's library, written at the start.
#  - melonDS: applied and put back (top-level keys, a new section, a value changed meanwhile kept), left from
#    a start the launcher didn't see end, and a real start of the fake melonDS.
#  - melonDS DS: its rows from the definition while the core lists no settings.

type Tester

wait 900
