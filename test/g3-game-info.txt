# Game info. Run by g3-game-info.ps1, which makes the test folder T: fake
# emulators under the shipped definitions, made-up games, packages, keys and .nsp files.
#  - PS4 (Bloodborne-like): version with the update beside it (01.00 → 01.09) and three add-ons by name,
#    wrong packages refused, an older update refused, a newer one replaces it, an add-on is added, a new cover.
#  - Switch in Eden with keys: 1.0.0, an update and an add-on kept in Ionea's folder (Eden's game folders),
#    and Eden's two mods for it from user\load (one turned off in Eden), not another game's.
#  - Switch in yuzu without keys: Version unknown, and the row to Required files.
#  - Wii U in Cemu: v0 → v208 from Cemu's title folder, an add-on folder copied in.
#  - GBA: Original, no updates section.
wait 900
type Tester
key accept
wait 900
key accept
wait 1500
romgame Bloodborne|T\games\CUSA00900\eboot.bin|shadPS4
romgame Test Quest|T\games\Switch\Test Quest [0100ABCD00010000][v0].nsp|Eden
romgame Test Quest Y|T\games\Switch\Test Quest [0100ABCD00010000][v0].nsp|yuzu
romgame Test Kart|T\games\WiiU\code\game.rpx|Cemu
romgame Test Adventure|T\games\Test Adventure.gba|mGBA

# PS4
gameinfo Bloodborne
expect screen GameInfoCard
expect info Version|01.00 → 01.09
expect infosection yes
expect infoaddons The Old Hunters | Soundtrack | Dynamic Theme
expect info Game ID|CUSA00900
expect info Region|USA
expect info Last played|Never
expect info Play time|0 min
expect infokind ps4-pkg
expect cardrows Add update or add-on | Display | Rename | Change cover | Cover colour | Adjust cover
shot g3-ps4-info
addonpick T\pkg\notapkg.pkg
waitaddon 20
expect screen AddonCard
expect addon refused: This file is not a PS4 package.
key back
wait 1200
expect screen GameInfoCard
addonpick T\pkg\other.pkg
waitaddon 20
expect addon refused: This package is for CUSA00003, not this game (CUSA00900).
key back
wait 1200
addonpick T\pkg\base.pkg
waitaddon 20
expect addon refused: This is the game itself, not an update or add-on.
key back
wait 1200
addonpick T\pkg\upd-0105.pkg
waitaddon 30
expect addon refused: Update 01.09 is already installed.
shot g3-ps4-refused
key back
wait 1200
addonpick T\pkg\upd-0110.pkg
waitaddon 30
expect addon ok: Update 01.10 is installed.
shot g3-ps4-installed
key accept
wait 1200
expect screen GameInfoCard
expect info Version|01.00 → 01.10
addonpick T\pkg\dlc-chalice.pkg
waitaddon 30
expect addon ok: Chalice Set is installed.
key back
wait 1200
expect infoaddons Chalice Set | The Old Hunters | Soundtrack | Dynamic Theme
coverpick T\cover.png

# a new cover opens Adjust cover first
key back

key back
