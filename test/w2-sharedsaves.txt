# Shared saves for a native port and its emulator. Run by w2-sharedsaves.ps1 (a fake shadPS4 and a
# fake bbport, one made-up Bloodborne folder). The save files are a few words each, written in the new profile's
# own folders with a chosen age:
#   SPRJ0005  both have it, the emulator's is newer -> the emulator's is kept, the port's goes to a backup, linked
#   SPRJ0006  both have it, the port's is newer     -> the port's becomes the shared one, the emulator's is backed up
#   SPRJ0007  only the port has it                  -> moved to the emulator's place and linked
#   SPRJ0008  only the emulator has it              -> linked in the port's place
#   SPRJ0005.sce_sys  the port's own metadata       -> never touched
# Then Separate: the port gets its own copies, and a later change on the port side stays there. No game is started.
wait 900
type Tester
key accept
wait 900
key accept
wait 1500
romgame Bloodborne|T\esde\ROMs\ps4\Bloodborne [CUSA00900]\eboot.bin|shadPS4
expect savesmode Bloodborne|Shared
profilewrite saves\shadps4\user\home\1000\savedata\CUSA00900\SPRJ0005\userdata0000|emu newer|10
profilewrite saves\shadps4\user\home\1000\savedata\CUSA00900\SPRJ0005\sce_sys\param.sfo|emu meta|10
profilewrite saves\bloodborne-bbport\user\savedata\1\CUSA00900\SPRJ0005\userdata0000|port older|60
profilewrite saves\bloodborne-bbport\user\savedata\1\CUSA00900\SPRJ0005.sce_sys\param.bin|port meta|60
profilewrite saves\shadps4\user\home\1000\savedata\CUSA00900\SPRJ0006\userdata0000|emu older|60
profilewrite saves\bloodborne-bbport\user\savedata\1\CUSA00900\SPRJ0006\userdata0000|port newer|10
profilewrite saves\bloodborne-bbport\user\savedata\1\CUSA00900\SPRJ0007\userdata0000|port only|10
profilewrite saves\shadps4\user\home\1000\savedata\CUSA00900\SPRJ0008\userdata0000|emu only|10
syncsaves Bloodborne
profilelog
log mark shared
syncsaves Bloodborne
log mark again
gamesaves Bloodborne|separate
expect savesmode Bloodborne|Separate
profilewrite saves\bloodborne-bbport\user\savedata\1\CUSA00900\SPRJ0005\userdata0000|port separate|0
syncsaves Bloodborne
log mark separate
quit
