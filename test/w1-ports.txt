# Native ports. Run by w1-ports.ps1, which makes the test
# folder T: a fake shadPS4 and a fake Bloodborne port (bbport-run.exe, which starts its game program
# bb-probe.exe as bbport does), all copies of TestGame.exe, and three made-up PS4 game folders (a few bytes
# and a param.sfo each, nothing real):
#   Bloodborne [CUSA00900]  01.00 with a "-patch" folder 01.09  -> both installed: every start asks Play with
#   Bloodborne [CUSA00207]  01.00, no update                    -> the port refuses it with the reason
#   Bloodborne [CUSA03173]  01.09, its emulator is the port      -> only the port: starts natively, no question
# The Discord status says PC for a native start, the emulator's name otherwise (discordwish).
# The hold menu has Launch at the top instead of Play with, A asks each time with the last
# answer focused, Game settings asks whose settings when both are installed, settings sit in boxes.
wait 900
type Tester
key accept

key accept

# 1. definitions: the port is found like an emulator, never as one
expect emus 2
expect defforexe bbport-run.exe|bloodborne-bbport
romgame Bloodborne|T\esde\ROMs\ps4\Bloodborne [CUSA00900]\eboot.bin|shadPS4
romgame BB Old|T\esde\ROMs\ps4\Bloodborne [CUSA00207]\eboot.bin|shadPS4
romgame BB Solo|T\esde\ROMs\ps4\Bloodborne [CUSA03173]\eboot.bin|Bloodborne (bbport)
expect playwith Bloodborne|ask
expect playwith BB Old|ask
expect playwith BB Solo|Bloodborne (bbport)
expect portwhy Bloodborne|ok
expect portwhy BB Solo|ok
expect portwhy BB Old|Bloodborne (bbport) needs Bloodborne 01.09. This copy is 01.00 with no update. Add the update in Game info first.
