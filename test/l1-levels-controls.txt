# Levels, own controls, re-reading. Run by l1-levels-controls.ps1,
# which makes the test folder T: fake Eden, Azahar, melonDS, DuckStation, found in the Emulators folder.
#  1. Found on the PC: "Ionea manages controls" on, as for every emulator, and an entry from
#     before the switch: on too. Support shows the level and its limits.
#  2. Off (switched off here): a start leaves the emulator's controls file alone and says "Its own controls".
#  3. Its page: Support, the switch, "Open the emulator" last before Done. On: a start writes them.
#  4. Open the emulator: inside the launcher, a value changed in it shows on its pages after it closes.
#  5. Controls changed in it while Ionea manages them: keep the emulator's (the switch goes off).
#  6. Esc menu: Open the emulator closes the game, then opens the emulator inside.
#  7. Set up for the controller: Eden, Azahar and melonDS get the XInput controller's buttons.
wait 900
type Tester
key accept
wait 900
key accept
wait 1500

# 1. found on the PC
expect emus 4
expect emucontrols Eden|on
expect emucontrols Azahar|on
expect support Eden|Managed
expect support DuckStation|Known · its own controls
emucontrols Azahar|unset
expect support Azahar|Managed
emucontrols Eden|off
expect support Eden|Managed · its own controls
romgame Test Quest|T\games\Test Quest [0100ABCD00010000][v0].nsp|Eden

# 2. off: a start changes nothing in its controls file
select Test Quest
wait 500
key accept
waitshown 30
wait 1500
expect ingame Test Quest
closegame
waitlaunch 20
expect ingame none
expect ini T\emus\Eden\user\config\qt-config.ini|[Controls]player_0_button_a|"engine:keyboard,code:67,toggle:0"
log mark started-off

# 3. its page
emucard Eden
expect screen EmulatorCard
expect cardrows Systems | File types | Start options | Program | Required files | Support | Open the emulator | Ionea manages controls | Play inside Ionea | Settings for every game | Remove from Ionea | Done
expect rowvalue Ionea manages controls|Off
expect rowvalue Support|Managed · its own controls
shot l1-eden-page-off
cardrow Ionea manages controls
key accept
wait 300
expect rowvalue Ionea manages controls|On
expect rowvalue Support|Managed
expect emucontrols Eden|on
shot l1-eden-page-on
emucard DuckStation
expect norow Ionea manages controls
expect rowvalue Support|Known · its own controls
key back
wait 300
key back
wait 400
select Test Quest
wait 500
key accept
waitshown 30
wait 1500
closegame
waitlaunch 20
expect ingame none
log mark started-on

# 4. open the emulator: inside the launcher, read again when it closes
emutweaks Eden
expect rowvalue Resolution|1x (native)
key back
wait 500
openemu Eden
waitemuin 20
expect emuopen Eden
expect emuinside yes
expect screen EmuOpen
shot l1-eden-open
iniset T\emus\Eden\user\config\qt-config.ini|[Renderer]resolution_setup\default|false
iniset T\emus\Eden\user\config\qt-config.ini|[Renderer]resolution_setup|6
closeemu
waitemu 15
expect emuopen none
expect screen EmulatorCard
expect cardfocus Open the emulator
cardrow Settings for every game
key accept
wait 400
expect screen TweaksCard
expect rowvalue Resolution|2x
shot l1-eden-reread
key back
wait 500
expect screen EmulatorCard

# 5. controls changed in it while Ionea manages them
openemu Eden
waitemuin 20
expect emuinside yes
iniset T\emus\Eden\user\config\qt-config.ini|[Controls]player_0_button_a|"engine:keyboard,code:88,toggle:0"
closeemu
waitemu 15
expect screen ControlsKeepCard
expect cardrows Keep Eden's | Keep Ionea's
shot l1-keep
cardrow Keep Eden's
key accept
wait 500
expect emucontrols Eden|off
expect screen EmulatorCard
expect rowvalue Ionea manages controls|Off
key back
wait 400

# 6. Esc menu: close the game, then open the emulator
select Test Quest
wait 500
key accept
waitshown 30
wait 3000
expect ingame Test Quest
homebutton
wait 800
expect screen HomeMenuCard
cardrow Game settings
key accept
wait 400
expect menupage settings
expect cardrows Game settings | Display | Open the emulator
shot l1-menu-settings
cardrow Open the emulator
key accept
waitemuin 30
expect ingame none
expect emuopen Eden
expect emuinside yes
closeemu
waitemu 15
expect emuopen none

# 7. set up for the controller
emucontrols Eden|on
emucontrols Azahar|on
emucontrols melonDS|on
inputset Main pad
controls switch
writecontrols Eden
controls 3ds
writecontrols Azahar
controls nds
writecontrols melonDS
quit
